## Ep.5 Revenge

จิ้งจอกปล่อยพลังขั้นสูงสุด กลายร่างเป็นซุปเปอร์ไซย่า

จิ้งจอกบินไล่ตามหาฐานของศัตรู 

เมื่อจิ้งจอกเผชิญหน้ากับอดีตเพื่อน เขาก็เริ่มชาร์จพลัง
แล้วปล่อยใส่ศัตรููคู่อาฆาตไม่ยั้ง จนเละเป็นผุยผง
แต่แค้นนี้ยังไม่จบ ยังมีอีกหนี้นึงที่ต้องชำระ

จิ้งจอกได้ทำการแกะรอบไปหลายร้อยไมล์จนเจอฐานลับขอไอพวกกลุ่มมาเฟีย

แต่แล้วเมื่อจิ้งจอกได้ทำการลักลอบเข้าไปในฐาน
แต่แล้วก็โดนฝ่ายศัตรูจับได้

จิ้งจอกโดนขังใว้ในคุกชั้นใต้ดิน 1000ชั้น!!!
